# PM Copilot — 产品经理 AI 工作流

一套可迁移的产品经理 AI 工作流，覆盖「需求 → 分析 → 评审 → PRD → 原型 → 飞书发布」全链路，以 Skills 形式组织，可在 Claude Code、Codex、Kiro、DeepSeek harness 等 agent 工具中运行。

## 快速上手

1. **必须先读** `CLAUDE.md` 顶部的「未定制警示」，再按 `docs/改造指南.md` 完成定制
2. 定制完成后，说「我有一个需求：……」即可开始

## 文档导航

| 文档 | 内容 |
|------|------|
| `CLAUDE.md` | 工作流入口 + 全局约定 |
| `docs/使用说明-SOP.md` | ⭐ 给人看的 SOP：是什么、怎么用、含架构图 |
| `docs/改造指南.md` | ⭐ 从通用版改造成你自己版本的分步清单 |
| `docs/安装与启用说明.md` | 环境依赖 + 启用步骤 |
| `docs/知识包挂载说明.md` | 怎么建、挂载业务知识包 |
| `docs/飞书集成配置说明.md` | 飞书可选集成（权限 scope / 授权） |

## 核心能力

- **主持人统一编排**：意图识别、阶段锁定、节点衔接
- **多专家轮审**：业务/合规/财务/UX/数据五视角扩展思考广度
- **PRD + 原型联合交付**：模板化撰写 + 静态 HTML 原型
- **模拟评审**：前端/后端/测试/产品前置发现问题
- **人工关键决策门禁**：外部写入、发布、通知均需明确确认


## 转分享须知

如需基于本工作流二次定制后转给他人，发布前跑一次 `node scripts/build_share.mjs` 校验：确认无敏感值（token/webhook）、无未填占位符残留后再压缩分发。
