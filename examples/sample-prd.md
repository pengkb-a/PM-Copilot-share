# PRD：会员积分兑换商城（示例）

> 完全虚构示例。这里演示的是 PRD 的**核心章节结构**，完整模板见 `prd-template` 技能。

## 1. 需求背景

用户积分盈余但缺少消耗场景，积分活跃度和会员留存偏低。

## 2. 目标

让会员用户可用积分兑换商品，提升积分消耗与活跃。

## 3. 目标用户与场景

| 用户 | 场景 |
|------|------|
| 会员用户 | 浏览商品 → 兑换下单 → 查看订单进度 |

## 4. 功能范围

### 4.1 商品浏览
- 商品列表：图片、名称、所需积分、库存状态
- 筛选：全部 / 可兑换 / 已兑完

### 4.2 兑换下单
- 校验：积分是否充足
- 确认：扣减积分，生成订单

### 4.3 兑换记录
- 订单列表：商品、积分、状态
- 状态：待发货 / 已发货 / 已完成

## 5. 业务规则

| # | 规则 |
|---|------|
| 1 | 积分不足不可下单 |
| 2 | 兑换成功积分实时扣减、不可退 |
| 3 | 库存为 0 展示「补货中」、不可兑换 |

## 6. 边界与异常

| 场景 | 处理 |
|------|------|
| 下单瞬间库存变 0 | 提示「商品已兑完」，不扣积分 |
| 并发重复提交 | 幂等控制，同一订单只提交一次 |

## 7. 埋点与指标

- 兑换点击率、兑换成功率、人均积分消耗

## 8. 待确认项

- 是否支持「积分 + 现金」混合支付
