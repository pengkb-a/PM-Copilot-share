# 从通用版改造成你自己的版本（给人和 AI 的分步清单）

> 本文档是把本工作流从「未定制」改造成「你自己的版本」的唯一操作入口。**人**可以照着做，**AI 助手**也可以按本清单逐项执行。
>
> **完成标准**：运行 `node scripts/replace_check.mjs` 输出「无待改造项」。

---

## 第 0 步：装依赖

- [ ] 安装 Node.js ≥ 18（`.mjs` 脚本依赖顶层 await / fetch）
- [ ] `cd feishu/mcp-server && npm install`（安装 MCP server 依赖）
- [ ] 在你的 agent 工具中启用 `feishu-doc` MCP server（若 `.mcp.json` 未自动加载）

## 第 1 步：决定启用哪些集成（默认全关）

- [ ] 复制 `config/integration-config.example.json` → `config/integration-config.json`
- [ ] 把不需要的集成保持 `false`；需要的改为 `true`
  - `feishu`：飞书文档发布
  - `notification`：机器人通知
  - `menuList`：菜单清单（第二阶段，先留 `false`）

> 规则：`integration-config.json` 不存在或某项 `false`，对应集成一律不触发。

## 第 2 步：填写项目背景

- [ ] 按 `config/project-context-template.md` 的结构，填写 `CLAUDE.md` 里的「项目背景（待填写）」段
- [ ] 替换所有 `{{...}}` 占位符（`{{PRODUCT_NAME}}`、`{{PROJECT_NAME}}` 等）
- [ ] 删除「待填写」提示语

## 第 3 步：（可选）自建知识包

- [ ] 复制 `config/knowledge-pack-template.md`，重命名为你的领域名，放入 `knowledge/` 目录
- [ ] 补全顶部元信息：`name` / `scope` / `owner` / `version` / `source` / `lastReviewed`
- [ ] 挂载说明见 `docs/知识包挂载说明.md`

## 第 4 步：（可选）配置飞书

- [ ] 复制 `feishu/.env.example` → `feishu/.env`，填 `FEISHU_APP_ID` / `FEISHU_APP_SECRET`
- [ ] 按 `docs/飞书集成配置说明.md` 的 scope 清单在飞书开放平台配权限
- [ ] `cd feishu && node feishu_doc.mjs login` 完成授权
- [ ] 如需机器人通知，填 `FEISHU_BOT_WEBHOOK`

## 第 5 步：校验

- [ ] 运行 `node scripts/replace_check.mjs`，确认输出「无待改造项」
- [ ]（可选）按 `examples/` 跑通一个虚构需求（本地模式，不发布飞书）

## 完成

上述清单全部勾选后，即完成定制，可正式使用。原工作流的「未定制警示语」可保留（无害）或删除。
