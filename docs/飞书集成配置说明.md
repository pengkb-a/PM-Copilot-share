# 飞书集成配置说明（可选）

飞书是**可选集成，默认关闭**。启用需完成：建自建应用 → 配权限 → 填 `.env` → 授权。

## 一、建自建应用

1. 登录 [飞书开放平台](https://open.feishu.cn)，创建「企业自建应用」
2. 拿到 `App ID` 和 `App Secret`，填入 `feishu/.env`

## 二、权限 scope 清单

在应用「权限管理」中添加（并按需开通）：

| scope | 用途 |
|-------|------|
| `docx:document` / `docx:document:write` | 创建、写入 PRD 文档 |
| `drive:drive` | 建文档、传文件、开分享权限 |
| `board:whiteboard:node:create` / `board:whiteboard:node:read` | 插入可编辑画板流程图 |
| `contact:user.base:readonly` | OAuth 登录取用户身份 |
| `offline_access` | 获取 refresh token，长期免登录 |

## 三、配置 `.env`

复制 `feishu/.env.example` → `feishu/.env`，关键项：

| 项 | 必填 | 说明 |
|----|------|------|
| `FEISHU_APP_ID` / `FEISHU_APP_SECRET` | 是 | 应用凭证 |
| `FEISHU_TENANT_DOMAIN` | 是 | 你的 `xxx.feishu.cn` |
| `FEISHU_FOLDER_TOKEN` | 否 | PRD 建到哪个文件夹 |
| `FEISHU_BOT_WEBHOOK` | 否 | 机器人通知（不填则静默关闭） |

## 四、首次授权

```bash
cd feishu && node feishu_doc.mjs login
```

浏览器弹出授权页，用你的飞书账号点「同意」。成功后 token 自动续期（refresh token 约 30 天，过期需重新 login）。

## 五、机器人通知

在飞书群里「设置 → 群机器人 → 添加自定义机器人」，复制 webhook 填入 `FEISHU_BOT_WEBHOOK`。通知统一走：

```bash
node notify.mjs "通知内容"
```

未配置 webhook 时该命令打印「通知已跳过」并正常退出，不影响主流程。

## 六、默认行为边界

- PRD **不默认**同步飞书，只有你明确说「发布到飞书」才执行
- 新文档**默认不公开**，只有你明确选权限才设公开
- 通知**默认关闭**，发送前给你内容预览确认
