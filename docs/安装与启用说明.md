# 安装与启用说明

## 一、目录结构

```
PM-Copilot-share/
├── CLAUDE.md                 # 工作流入口（含未定制警示）
├── README.md                 # 总介绍
├── .mcp.json                 # 飞书 MCP 配置（相对路径）
├── .claude/skills/           # 全部技能
├── feishu/                   # 飞书集成脚本（可选）
├── config/                   # 配置模板
├── docs/                     # 说明文档
├── knowledge/                # 知识包存放处
├── examples/                 # 虚构示例
└── scripts/                  # 打包 / 校验脚本
```

## 二、环境依赖

- Node.js ≥ 18
- 一个支持 Skills / MCP 的 agent 工具：Claude Code、Codex、Kiro、DeepSeek harness 等均可

## 三、启用步骤

1. 把本目录用任意 agent 工具打开作为项目
2. 阅读 `CLAUDE.md` 顶部的「未定制警示」，按 `docs/改造指南.md` 完成定制
3. 如需飞书：`cd feishu/mcp-server && npm install`，并在你的 agent 工具里启用 `feishu-doc` MCP server

## 四、跑通验证

- 说一句「我有一个需求：……」，主持人应能引导你走「需求分析 → PRD → 原型」
- 本地模式默认不出飞书；发布到飞书需要先完成飞书配置

## 五、常见问题

| 现象 | 处理 |
|------|------|
| MCP 工具不可见 | 检查 `.mcp.json` 是否加载、`npm install` 是否执行 |
| 飞书返回 `AUTH_REQUIRED` | `cd feishu && node feishu_doc.mjs login` 重新授权 |
| 通知没发 | 检查 `FEISHU_BOT_WEBHOOK` 是否填写 |
