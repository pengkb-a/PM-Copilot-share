# 知识包挂载说明

公共包里**不携带任何真实业务知识**。业务知识通过「知识包」按需挂载，避免 AI 在无上下文时瞎猜规则。

## 一、知识包是什么

一个 Markdown 文件，带统一元信息，描述某个领域（财务、某业务线、对账规则等）的术语、规则、约束。

模板：`config/knowledge-pack-template.md`，复制后改名放入 `knowledge/` 目录。

## 二、元信息 schema（顶部 yaml）

```yaml
---
name: 财务领域知识包
scope: finance
owner: [维护团队]
visibility: internal
version: 1.0.0
source: [制度 / 规范 / 经确认资料]
lastReviewed: YYYY-MM-DD
---
```

| 字段 | 必填 | 说明 |
|------|------|------|
| `name` | 是 | 知识包名称 |
| `scope` | 是 | 作用域（finance / 业务线A / 对账…） |
| `owner` | 是 | 维护团队 |
| `visibility` | 是 | internal / confidential |
| `version` | 是 | 版本号 |
| `source` | 建议 | 来源，保证可追溯 |
| `lastReviewed` | 建议 | 最近评审日期 |

## 三、如何挂载（AI 的加载规则）

- 流程运行时**检测到领域术语**，会询问你「是否加载对应知识包」。
- 你挂载后，AI 基于该知识包的规则回答；**未挂载时不自行假设**，而是向你澄清。
- 没有对应知识包时，AI 只能问你，不能编造。

## 四、维护规则

- 每次口径变更，更新知识包并更新 `lastReviewed` / `version`
- 来源必须可追溯（制度 / 会议 / 确认人）
