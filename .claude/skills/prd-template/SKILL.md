# PRD 输出模板

## 输出格式说明

**优先输出 HTML 格式**：所有新生成的 PRD 应基于 `PRD文档/_模板/PRD模板.html` 模板创建，原因：

1. 一号标题大字居中、章节自动编号（CSS counter）等飞书友好的样式开箱即用
2. 表格自带"复制为列表"功能，粘贴到飞书后自动转为原生列表（不会变 Excel 块）
3. 原型图占位框支持双击/拖拽/粘贴上传
4. 工具栏支持一键导出 HTML / Word / Markdown，用户可自行转换格式
5. 章节结构和命名规范已经内置，不需要 AI 重复造轮子

**Markdown 仍然支持**：用户在 HTML 编辑完成后，点击"📝 导出 Markdown"即可获得 .md 文件。如果用户明确要求"直接生成 Markdown"，则按下方模板格式生成 .md。

**章节编号约定**：HTML 模板用 CSS counter 自动渲染编号，不需要在标题文字里手动写"1. ""2.1 "这种前缀。

---

PRD 文档必须严格遵循以下结构和写法规范。生成时仅输出用户确认的章节，未选中的章节不输出。

---

## 标题层级规则（重要！）

为适配飞书文档导入，PRD 文件的标题层级规则如下：

1. **不使用 `#`（一号标题）** — 飞书不支持 H1，去掉文档标题行
2. **章节标题用 `##`** — 飞书导入后显示为 H1（如 `## 修订记录`）
3. **子章节用 `###`** — 飞书导入后显示为 H2（如 `### 需求背景`）
4. **标题不带序号** — 不写 `## 1. 修订记录`，直接写 `## 修订记录`
5. **需求详情中的功能模块用 `###`** — 如 `### 全业务订单列表（变更）`

---

## 必选章节

每份 PRD 都必须包含：
- 修订记录
- 需求概述（需求背景 + 需求目标 + 本期功能清单）
- 需求详情

## 按需章节

| 章节 | 包含条件 |
|------|---------|
| 名词解释 | 涉及读者可能不熟悉的专业术语或新概念 |
| 需求价值 & 预估收益 | 需要说明业务价值时 |
| 需求风险描述 | 存在明显风险或不确定性 |
| 功能框架 | 涉及多模块、多系统或复杂流程 |
| 协同需求 | 需要跨系统/跨部门协作 |
| 待办项 | 本期不做但后续需要迭代的事项 |

> 风险项：简短命名，如"XX 稳定性""XX 数据不完整"

| 风险项 | 说明 | 应对方案 |
|--------|------|----------|
| | | |

> 用文字段落描述系统定位，再用短横线列表说明各层职责。不需要画架构图。

### 业务流程

> 流程图类型选择：
> - 多系统交互 → flowchart TD，用 subgraph 区分各系统

## 报表类需求专用模板

> ⚠️ 当需求类型为**报表/数据统计**时，页面说明和功能操作的结构与通用模板不同，必须使用以下专用结构。
> 判断标准：需求的核心是"查看聚合数据"而非"操作业务流程"，如充值报表、结算报表、收益报表等。

### 报表页面结构

```markdown
##### X.X.1 页面说明

**1. 字段说明**

| 字段 | 说明 | 示例 |
|------|------|------|
| **筛选区** | | |
| [字段名] | [控件类型]，[枚举值/查询方式]，默认[默认值] | |
| **列表区** | | |
| 字段参考报表口径 | 空值显示"—" | |

**2. 统计数据区**

| 区域 | 说明 |
|------|------|
| 合计-首行 | 置顶在表头下的第一行，与表头全局固定。求和按当前查询结果单列数据求和。仅统计：[列出需要合计的字段] |

**3. 报表口径**

| 字段 | 口径 | 示例 |
|------|------|------|
| [字段名] | [数据来源 + 聚合维度 + 计算方式] | [示例值] |

**4. 数据规则**

- [通用规则，不重复口径中已说明的字段计算逻辑]

**5. 排序规则**

- [默认排序字段和方向]

##### X.X.2 功能操作

###### X.X.2.1 导出

- 按当前筛选条件导出全部数据，格式 Excel（.xlsx），走下载中心异步下载

##### X.X.3 其他说明

- 分页：默认展示 [N] 行，超出分页
- 空状态：列表无数据时显示"暂无数据"；筛选无结果时显示"未查询到符合条件的数据"；字段值为空时统一显示"—"
```

### 报表类需求的关键规则

1. **查询/重置不写** — 框架基础能力，不需要在功能操作中单独说明
2. **导出简化** — 只写"按当前筛选条件导出全部数据"一句话，不写详细交互逻辑
3. **列表区字段简化** — 有报表口径时，列表区只写一行"字段参考报表口径"，不逐字段重复
4. **报表口径是核心** — 替代通用模板中的"数据来源"章节，每个字段的计算逻辑、聚合维度都在口径表中说明
5. **统计数据区必写** — 如果有合计行，必须说明位置（表头下方固定）和统计范围
6. **数据规则不重复** — 只写通用规则，不重复口径中已说明的内容
