## 模块一：会计基础

### 1.1 会计要素（六要素）

| 要素 | 定义 | 借方增加 | 贷方增加 | 常见科目 |
|------|------|---------|---------|---------|
| 资产 | 企业拥有或控制的经济资源 | ✓ | | 现金、银行存款、应收账款、固定资产 |
| 负债 | 企业承担的现时义务 | | ✓ | 应付账款、预收账款、应交税费、合同负债 |
| 所有者权益 | 资产减去负债后的剩余权益 | | ✓ | 实收资本、资本公积、未分配利润 |
| 收入 | 日常活动中形成的经济利益流入 | | ✓ | 主营业务收入、其他业务收入 |
| 费用 | 日常活动中形成的经济利益流出 | ✓ | | 主营业务成本、管理费用、销售费用、财务费用 |
| 利润 | 收入减去费用后的净额 | | ✓ | 本年利润、利润分配 |

### 1.2 会计等式

```
资产 = 负债 + 所有者权益（静态等式）
收入 - 费用 = 利润（动态等式）
资产 = 负债 + 所有者权益 +（收入 - 费用）（综合等式）
```

### 1.3 借贷记账法核心规则

**口诀**：有借必有贷，借贷必相等。

| 账户类型 | 借方 | 贷方 | 余额方向 |
|---------|------|------|---------|
| 资产类 | 增加 | 减少 | 借方余额 |
| 负债类 | 减少 | 增加 | 贷方余额 |
| 权益类 | 减少 | 增加 | 贷方余额 |
| 收入类 | 减少（冲减） | 增加 | 期末无余额（结转） |
| 费用类 | 增加 | 减少（冲减） | 期末无余额（结转） |

## 模块二：科目体系

### 2.1 科目分类

| 大类 | 编码段 | 说明 | 期末有余额 |
|------|--------|------|-----------|
| 资产类 | 1xxx | 企业拥有的资源 | 有（借方） |
| 负债类 | 2xxx | 企业欠别人的 | 有（贷方） |
| 权益类 | 3xxx | 股东的钱 | 有（贷方） |
| 成本类 | 4xxx/5xxx | 生产成本、制造费用 | 有（借方） |
| 损益类-收入 | 6xxx | 赚的钱 | 无（期末结转） |
| 损益类-费用 | 6xxx | 花的钱 | 无（期末结转） |

### 2.2 科目层级

```
1002 银行存款（一级，汇总科目，不能直接记账）
├── 100201 银行存款-微信（二级，末级，可记账）
├── 100202 银行存款-支付宝（二级，末级，可记账）
└── 100203 银行存款-工行基本户（二级，末级，可记账）
```

**关键规则**：只有末级科目才能在凭证中使用。

### 2.3 核算维度（辅助核算）

核算维度是科目的"附加标签"，用于更细粒度的核算：

| 维度类型 | 用途 | 举例 |
|---------|------|------|
| 部门 | 按部门归集费用/收入 | 平台产品部、运营部 |
| 客户 | 按客户核算应收 | 微信支付商户 |
| 供应商 | 按供应商核算应付 | 供应商A、供应商B |
| 员工 | 按员工核算借款/报销 | 张三 |
| 项目 | 按项目归集成本 | 工程项目 |
| 银行账号 | 区分不同银行账户 | 工行XXX账户 |
| 费用项目 | 细分费用类别 | 支付手续费、服务器费用 |

### 2.4 损益科目 vs 资产负债科目

| 对比 | 损益科目 | 资产负债科目 |
|------|---------|-------------|
| 期末余额 | 无（结转到本年利润） | 有 |
| 影响报表 | 利润表 | 资产负债表 |
| 结转损益 | 需要（每月/每年） | 不需要 |
| 举例 | 主营业务收入、管理费用 | 银行存款、应付账款 |

## 模块三：凭证管理

### 3.1 凭证结构

```
┌─────────────────────────────────────────────────┐
│ 凭证头                                           │
│ 凭证字：记  凭证号：001  日期：2026-03-31         │
│ 附件：2张   制单人：系统                          │
├─────────────────────────────────────────────────┤
│ 分录1：摘要    科目         借方      贷方        │
│        微信充值  银行存款-微信  258,000            │
│        [部门：平台产品部]                         │
├─────────────────────────────────────────────────┤
│ 分录2：摘要    科目         借方      贷方        │
│        微信充值  合同负债              258,000     │
├─────────────────────────────────────────────────┤
│ 合计                       258,000   258,000     │
│                            借贷平衡 ✓            │
└─────────────────────────────────────────────────┘
```

### 3.2 凭证字使用规则

| 凭证字 | 使用场景 | 判断标准 |
|--------|---------|---------|
| 记 | 通用记账凭证 | 不区分收付转时统一用"记" |
| 收 | 收款业务 | 借方有现金/银行存款科目 |
| 付 | 付款业务 | 贷方有现金/银行存款科目 |
| 转 | 转账业务 | 不涉及现金/银行存款的凭证 |

### 3.3 凭证生命周期

```
制单（草稿）→ 审核 → 过账 → 结账
     ↑           ↓       ↓
     └── 反审核 ←─┘  反过账 ←─┘
```

| 状态 | 可修改 | 影响账簿 | 操作权限 |
|------|--------|---------|---------|
| 草稿 | 可以 | 不影响 | 制单人 |
| 已审核 | 不可以（需反审核） | 不影响 | 审核人 |
| 已过账 | 不可以 | 已计入余额 | 过账人 |
| 已结账 | 不可以 | 期间已关闭 | 需反结账 |

### 3.4 红冲与蓝补

| 方式 | 说明 | 使用场景 |
|------|------|---------|
| 红字冲销 | 用负数金额做一张与原凭证相同方向的凭证 | 原凭证错误，需要完全撤销 |
| 蓝字补充 | 用正数金额做一张补充凭证 | 原凭证金额不足，需要补记 |
| 红蓝结合 | 先红冲原凭证，再蓝字做正确凭证 | 原凭证科目或方向错误 |

### 3.5 凭证校验规则

| 校验项 | 规则 | 严重程度 |
|--------|------|---------|
| 借贷平衡 | 借方合计 = 贷方合计 | 阻断（必须满足） |
| 科目末级 | 只能使用末级科目 | 阻断 |
| 核算维度完整 | 科目要求的维度必须全部填写 | 阻断 |
| 现金流量 | 现金/银行科目必须指定流量项目 | 阻断（如开启） |
| 会计期间 | 日期在已开放期间内 | 阻断 |
| 金额非零 | 分录金额不能为零 | 阻断 |
| 摘要非空 | 每行分录必须有摘要 | 警告 |

## 模块四：现金流量

### 4.1 三大分类

| 分类 | 含义 | 常见项目 |
|------|------|---------|
| 经营活动 | 日常经营产生的现金流 | 销售收款、采购付款、支付工资、缴纳税费 |
| 投资活动 | 长期资产投资产生的现金流 | 购买设备、处置资产、投资收益 |
| 筹资活动 | 融资相关的现金流 | 借款、还款、分红、增资 |

### 4.2 现金及现金等价物

| 属于 | 不属于 |
|------|--------|
| 库存现金 | 定期存款（超3个月） |
| 银行活期存款 | 股票投资 |
| 其他货币资金（支付宝/微信余额） | 应收账款 |
| 3个月内到期的短期投资 | 存货 |

### 4.3 凭证中的现金流量分配

当凭证分录涉及现金/银行科目时，必须指定现金流量项目：

```
借：管理费用-办公费     1,000
贷：银行存款-工行       1,000  ← 银行科目，需指定流量

现金流量项目 = "购买商品、接受劳务支付的现金"（经营活动-流出）
```

### 4.4 直接法 vs 间接法

| 方法 | 编制方式 | 数据来源 |
|------|---------|---------|
| 直接法 | 逐笔凭证标记现金流量项目，汇总生成 | 凭证上的流量标记 |
| 间接法 | 从净利润出发，调整非现金项目 | 利润表 + 资产负债表变动 |

## 模块五：总账与报表

### 5.1 账簿体系

```
凭证 → 明细账（按科目逐笔记录）→ 总账（按科目汇总）→ 报表
```

### 5.2 三大财务报表

| 报表 | 反映内容 | 时间属性 | 核心等式 |
|------|---------|---------|---------|
| 资产负债表 | 某一时点的财务状况 | 时点数 | 资产 = 负债 + 权益 |
| 利润表 | 某一期间的经营成果 | 期间数 | 收入 - 费用 = 利润 |
| 现金流量表 | 某一期间的现金变动 | 期间数 | 期初现金 + 流入 - 流出 = 期末现金 |

### 5.3 报表勾稽关系

```
利润表的"净利润" → 资产负债表的"未分配利润"变动
现金流量表的"期末现金" → 资产负债表的"货币资金"
利润表的"净利润" → 现金流量表附表的起点（间接法）
```

## 模块六：应收应付

### 6.1 应收账款

| 概念 | 说明 |
|------|------|
| 应收账款 | 已确认收入但尚未收到款项 |
| 账龄分析 | 按欠款时间分段统计（30天内/30-60天/60-90天/90天以上） |
| 坏账计提 | 按账龄比例计提坏账准备（如90天以上计提50%） |
| 核销 | 确认无法收回时，冲减坏账准备和应收账款 |

### 6.2 应付账款

| 概念 | 说明 |
|------|------|
| 应付账款 | 已收到商品/服务但尚未付款 |
| 预付账款 | 先付款后收货/服务 |
| 往来核销 | 同一客商的应收应付互相抵消 |

### 6.3 与你们业务的关联

- 供应商结算 → 应付账款（欠供应商的分成款）
- 充值未消费 → 合同负债（预收性质）
- 押款 → 其他应付款

## 模块七：税务知识

### 7.1 增值税

| 概念 | 说明 | 你们的场景 |
|------|------|-----------|
| 销项税 | 销售时向客户收取的税 | 向供应商收取服务费时的税 |
| 进项税 | 采购时支付给供应商的税 | 收到供应商开具的发票中的税额 |
| 进项转出 | 不能抵扣的进项税转为成本 | 用于免税项目的采购 |
| 免税 | 不征收增值税 | 虚拟货币充值（需确认） |

### 7.2 发票管理

| 票种 | 特点 | 使用场景 |
|------|------|---------|
| 增值税专用发票 | 可抵扣进项税 | 一般纳税人之间的交易 |
| 增值税普通发票 | 不可抵扣 | 小规模纳税人开具 |
| 电子发票 | 与纸质发票同等效力 | 线上交易 |

### 7.3 企业所得税

- 税率：一般企业 25%，小微企业优惠税率
- 计算：应纳税所得额 × 税率
- 应纳税所得额 = 会计利润 ± 纳税调整

### 7.4 个人所得税

- 工资薪金：累进税率 3%-45%
- 劳务报酬：预扣 20%-40%，年度汇算
- 与你们的关联：供应商结算如果涉及个人，需要代扣代缴

## 模块八：期末处理

### 8.1 月末处理流程

```
1. 确认所有凭证已录入并审核
2. 计提折旧（固定资产）
3. 摊销（长期待摊费用）
4. 计提坏账准备
5. 期末调汇（外币账户）
6. 结转损益（损益科目→本年利润）
7. 对账（银行对账、往来对账）
8. 结账（关闭当期）
```

### 8.2 结转损益

将所有损益科目余额转入"本年利润"：

```
借：主营业务收入      1,000,000
借：其他业务收入        50,000
贷：本年利润                    1,050,000

借：本年利润            800,000
贷：主营业务成本                  500,000
贷：管理费用                      200,000
贷：销售费用                      100,000
```

### 8.3 期末调汇

外币账户按期末汇率重新计算本位币金额，差额计入"财务费用-汇兑损益"。

## 模块九：成本与收入

### 9.1 收入确认

| 时点 | 条件 | 你们的场景 |
|------|------|-----------|
| 充值时 | 收到款项 | 充值记"合同负债"（预收），不确认收入 |
| 消费时 | 用户消费虚拟货币 | 从"合同负债"转为"主营业务收入" |
| 服务完成时 | 服务已提供 | 供应商结算周期结束时确认成本 |

### 9.2 分成与结算

```
用户充值 100 元：
  借：银行存款          100
  贷：合同负债                100

用户消费（送礼）：
  借：合同负债          100
  贷：主营业务收入            100

供应商分成 60%：
  借：主营业务成本       60
  贷：应付账款-供应商A         60

支付供应商：
  借：应付账款-供应商A    60
  贷：银行存款                 60
```

### 9.3 佣金与手续费

```
渠道商佣金 30%：
  借：主营业务成本-渠道佣金   30
  贷：应付账款-渠道商            30

支付手续费：
  借：财务费用-手续费          0.6
  贷：银行存款                    0.6
```

## 模块十：业务财务一体化

### 10.1 业务单据→凭证的转换逻辑

| 业务事件 | 会计处理 | 凭证模板 |
|---------|---------|---------|
| 用户充值 | 银行存款↑ 合同负债↑ | 借：银行存款 贷：合同负债 |
| 用户消费 | 合同负债↓ 收入↑ | 借：合同负债 贷：主营业务收入 |
| 渠道手续费 | 费用↑ 银行存款↓ | 借：财务费用 贷：银行存款 |
| 供应商分成 | 成本↑ 应付↑ | 借：主营业务成本 贷：应付账款 |
| 支付供应商 | 应付↓ 银行存款↓ | 借：应付账款 贷：银行存款 |
| 用户退款 | 合同负债↓ 银行存款↓ | 借：合同负债 贷：银行存款 |

### 10.2 凭证接口对接说明

> 对接具体财务系统（ERP）时，凭证接口字段以目标系统接口文档为准，此处不再展开。

### 10.3 常见推送失败原因

| 错误 | 原因 | 解决方案 |
|------|------|---------|
| 科目不存在 | 编码错误或非末级 | 检查科目编码 |
| 核算维度缺失 | 科目要求维度但未传 | 补充维度值 |
| 借贷不平衡 | 金额计算错误 | 检查精度和四舍五入 |
| 期间未开放 | 凭证日期对应的期间已结账 | 调整日期或反结账 |
| 维度值不存在 | 传入的维度编码在财务系统中不存在 | 先在财务系统中创建维度数据 |
| 现金流量未指定 | 涉及现金科目但未传流量项目 | 补充现金流量项目编码 |
